Impostazioni

Configurazione di Azure DevOps usata da ingest, review e da questa dashboard. Il Personal Access Token non viene mai mostrato in chiaro: lascia il campo vuoto per non modificarlo. Le modifiche vengono scritte nel file .env locale e diventano subito attive, anche per i run avviati dai bottoni sopra.

Le voci Provider agente, Modello agente, Limite token output e Budget token totale sono menu a tendina. Per l'uso normale seleziona Claude Code e uno tra Opus, Sonnet o Haiku.
